# W8.1 — завершение ежедневного экрана «Остатки»

Дата: 2026-09-06
Baseline: `ed889662e9d6dc0fc5fdfdd95943bb5641a8db5b` (W7)
Branch: `w8-1-stock-overview-completion`

## Цель

Довести `Остатки` как главный ежедневный экран Склада без изменения складской математики. Существующий Product-список сохраняется, а раскрытие сложного товара становится человекочитаемым: **Исполнение → Цвет → пол/тип только при необходимости → крупные Размер/Возраст**. Каждый тайл остаётся точным SKU и открывает существующую безопасную быструю сверку.

## Изменения

- одинаковые цвета и исполнения больше не размазаны плоским списком SKU;
- размер/возраст — главный визуальный ориентир;
- на каждом точном тайле видны `Свободно`, `На месте`, а резерв показывается только когда он есть;
- отрицательный/сомнительный остаток не скрывается и визуально отделён;
- добавлена явная строка `товары / позиции в текущей выборке`, чтобы глобальные итоговые карточки не выглядели как результат поиска;
- мобильный экран использует крупные 3-колоночные тайлы;
- существующие quick-check, reservations, exact history и routine cycle-count пути переиспользуются без новых API/reads/writes.

## Не менялось

- Physical / Reserved / Available;
- reservation / movement / stocktake / lifecycle semantics;
- Worker/API/D1;
- Catalog;
- Arrival;
- Branch2;
- pricing.
